### Finding 2: Claude Code auto mode — "Approval Fatigue" statistical rationale now documented; enterprise rollout by ~Sep 14

**Source:** [https://www.infoworld.com/article/4207959/anthropic-makes-claude-codes-auto-mode-default-for-paid-users.html](https://www.infoworld.com/article/4207959/anthropic-makes-claude-codes-auto-mode-default-for-paid-users.html) — [general press citing Anthropic internal data]
**Source:** [https://www.helpnetsecurity.com/2026/08/10/anthropic-claude-code-auto-mode/](https://www.helpnetsecurity.com/2026/08/10/anthropic-claude-code-auto-mode/) — [domain trade publication]
**Source:** [https://simonwillison.net/2026/Aug/8/auto-mode/](https://simonwillison.net/2026/Aug/8/auto-mode/) — [practitioner direct]
**Date:** 2026-08-08 to 2026-08-14 (auto mode announcement → default rollout)
**Agent level:** personal / team / company
**What:** This cycle surfaces Anthropic's statistical rationale for making auto mode the default on August 14 — previously only documented as a feature, not a reasoned position. Key data: users approved **97%** of permission prompts reflexively (only 3% rejected); **49.5%** of CLI users had created Bash allow-rules by June; **62%** used "bypassPermissions" or "don't ask again" for Bash commands. In an internal study with **1,053 paid professional testers**, auto mode's classifier caught **89%** of deliberately dangerous commands vs **13.6%** caught by human reviewers. Anthropic's conclusion: the approval workflow created "approval fatigue" — a security theater where users rubber-stamped requests without genuine scrutiny. Auto mode's classifier demonstrably outperforms the human-review status quo. **Enterprise/API rollout timeline:** Enterprise, API, and cloud platform users (Bedrock, Vertex, Foundry) receive the same auto-mode default "within the next month" of August 14 = by approximately September 14, 2026. Enterprise rollout is ~8 days away from today's cycle date.
**Evidence level:** Level 2 (vendor-cited internal study, n=1,053 — Anthropic data, conflict of interest; study design and scope unknown; Willison confirms announcement August 8)
**Key claims:**
- 97% permission-prompt approval rate = the human-review model was already effectively bypassed
- 89% (auto mode) vs 13.6% (human reviewers) dangerous-command detection in internal study — an order-of-magnitude difference
- Enterprise/API rollout "within the next month" of August 14 = by approximately September 14, 2026
- CTO implication: Anthropic's statistical case for auto mode is stronger than the counter-narrative; the Rehberger "working as designed" position is internally coherent alongside these numbers — auto mode is a better security control than reflexive human approval, but is not a security boundary for determined multi-step adversarial chains
