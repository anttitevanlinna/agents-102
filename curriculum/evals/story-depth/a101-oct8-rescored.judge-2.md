## Frame
**A.** Frame in one sentence: agentic engineering is engineering, run as a feedback-control loop you verify and compound. Load-bearing in M3, M5 and M6; it also names where it breaks.
- M3 the-loop-half-filled: "The agent loop is a **closed-loop controller**... Cut the feedback signal (a test, a check, a read) and it drifts."
- M5 what-packaging-is: "**A check is a position fix**. At a fix the wedge of possible states collapses to a point."
- M6 composing-the-workflow: "You drew a control loop... The checks you built are the instruments inside it."
- Where it breaks, M5 the-gate-is-a-claim: "Sutton's **bitter lesson**: built-in human knowledge wins today and loses to the next model."
Score 93.

**B.** Frame in one sentence: an agent is a set of parts you assemble one decision at a time (context, memory, other agents, boundary, check, loop, interface), and what you put in decides what comes out. The "full agent picture" line recurs in every module.
- M1 context-is-king: "In the full agent picture, this is the first piece: context. Later you add tools, goals, checks, boundaries, and loops."
- M4 practice-of-risk: "In the full agent picture, this is the boundary piece."
- M7 access-is-not-absorption: "In the full agent picture, this is the interface piece. It is the first one that has another person on the other side of it."
- Where it breaks, M8 where-is-this-all-going: "Which half of this is obsolete next year?... Nobody in this room knows yet."
The frame holds every module together, but it is mostly signposted in one-line slides, and M3 is the weakest fit ("Other agents are part of the tool surface"). Score 84.
