## A hypothesis can meet a working slice the same day
<!--slide:hypothesis-meets-a-slice-->

Write the bet in the morning: this change will make these customers do this differently. By the afternoon an agent can have a clickable prototype, a landing-page variant or a first analytics query in front of you.

A test that used to wait for a sprint can now happen before the idea has gone cold.

It only works if the bet comes first. A slice built without one answers no question, however fast it arrived.
