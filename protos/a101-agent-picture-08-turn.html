PROTO A101-08 THE FULL AGENT PICTURE · TURN The loop is one round trip, repeated: text comes back, becomes tool calls here, results go back up with context and goal. The checks read what came out, at the door, before you do.

Idea

The loop is a round trip through the cloud: each turn the model sends back one answer, your runtime turns it into tool calls, and the results go back up with context and the goal.
The checks sit outside the loop, at the door: something reads what came out before you do, judges it against the goal, and its verdict is written into memory so the next run starts sharper.
The wall is the give / keep back decision; the cloud sits outside it by nature, so what goes up, goes up.

What it cannot show

How many turns a run takes, or when the runtime decides it is done; the "when done" branch is a single line.
That checks can also run inside a run (a test the agent calls as a tool), or be another call up to a model.
That the interface also carries the goal in; the door is drawn only as the way out to you.

Where it breaks

The verdict line to memory crosses the tool calls on its way down; the geometry, not the meaning, forces the crossing.
Tools and results are drawn as one call per turn; a real turn can call several tools before going back up.
