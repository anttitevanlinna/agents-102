# Pair reviewer against the maintainer's calls, first run

Set: antti-pairs, 55 pairs (branch `claude/project-thread-ztwsxp`, `curriculum/evals/calibration/antti-pairs/`). Reviewer: `scripts/sentence-pair-review.js`, default Claude model, each pair judged in both orders. A pick counts only when both orders agree.

| | reader only | reader + writing-style.md |
|---|---|---|
| position flips (no pick) | 17 / 55 | 17 / 55 |
| agreement on picked pairs | 18 / 38 (47%) | 19 / 38 (50%) |
| always-pick-the-shorter, same pairs | 61% | 53% |
| accepted-edit | 9 / 14 | 9 / 12 |
| refused-edit | 7 / 15 | 8 / 16 |
| antti-wording | 2 / 9 | 2 / 10 |
| voice | 0 / 5 | 0 / 5 |

## Reading

- The reviewer fails the bar (about 80% overall, no kind under 65%). On a third of the pairs it flips when the sides swap, so on those it has no preference at all.
- Where it does pick, it agrees with the maintainer about half the time, which is no better than picking the shorter version.
- It is weakest where taste lives: wording the maintainer supplied (about 20%) and voice (0 of 5). Adding the written style guide does not move it.
- Consequence for the loop: a plain pairwise LLM reviewer cannot choose winners. Until a reviewer clears the bar on this set, the loop only proposes variants and the maintainer decides every one.

Next reviewer variants to score on the same set: the simulated-student instrument (rubric work), a reviewer given the maintainer's taste notes as examples (score it on held-out pairs only, so it is not tuned on its test), and a majority across several readers.

## Second run: taste notes and past calls as examples

Set: antti-pairs v2 (74 pairs). Test = the 36 gold pairs not built from `taste-notes.md`, minus 6 shown as examples (2 refused, 2 accepted, 2 maintainer wording, seed 20261031). That leaves 30 held-out pairs. Both orders, stable picks only.

| | reader only | + taste-notes.md + 6 example calls |
|---|---|---|
| position flips (no pick) | 9 / 30 | 8 / 30 |
| agreement on stable picks | 9 / 21 (43%) | 15 / 22 (68%) |
| always-pick-the-shorter, same pairs | 76% | 82% |
| accepted-edit | 8 / 13 | 12 / 14 |
| refused-edit | 1 / 3 | 2 / 4 |
| maintainer wording | 0 / 5 | 1 / 4 |
| voice | 1 / 3 | 0 / 2 |

- The taste notes and examples lift agreement from 43% to 68%. Most of the gain is on accepted edits, mostly cuts.
- The reviewer still does not clear the bar, and it still does no better than picking the shorter version.
- Maintainer wording and voice stay near zero. The held-out set is small (22 stable picks), so read these as direction, not as a measurement.
- Consequence unchanged: the loop proposes, the maintainer decides. Voice and maintainer wording are where new calibration calls are most needed.
