<p>Want to see what Claude can make? Start with a file you’ll recognize as soon as you see it. Snake needs one message and none of your work files. Later you’ll make a briefing for your working week.</p>

## Pause learning

If you haven’t added the course files yet, bookmark the section you’re on. Otherwise, ask Claude to save your place.

**Prompt** Cowork

```text
Help me pause Agents 101 so I can resume later.

Use `prework/course-navigation.md` to save my place before we stop.
```

## Resume learning

If you bookmarked a section, open that bookmark. Otherwise, start a new Cowork session in Claude Desktop and add your `agents-101` folder.

**Prompt** Cowork

```text
Help me resume Agents 101.

Read `prework/course-navigation.md` and help me find my place in the workbook.
```
