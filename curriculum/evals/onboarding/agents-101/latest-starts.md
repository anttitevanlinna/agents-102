# Agents 101 first-start impressions

The revised ACME workbook averaged **4.43/5 stars** across 30 simulated starts, compared with **4.35/5** for the prior published workbook. The target is **4.50/5**. The revised version fell short.

30 of 30 readers expected to reach the game. Ten synthetic personas each read the HTML in three fresh calls. Every version used the same 1.0–5.0 question, with Cowork access and the demonstrations in the video captions assumed.

The two-step route puts Copy and Send together. It shows how to tell when the folder is attached, when Claude has saved the file, and where to open it on Mac and Windows. Readers still hesitated over the switch from Claude to the file browser and wanted a better sense of how long the build would take.

In a native Mac run, Claude asked for folder permission after selection and again after Send. It created the game in the empty folder using the same prompt. A separate request for a direct link returned a file URL as text, so the workbook gives the file-opening steps.

Persona scores measure perceived clarity through the first game. A separate native Mac run exercised the same prompt against an empty local folder and played the saved game in a browser. Elapsed time, human completion, Windows behavior and automatic course loading remain unmeasured.
