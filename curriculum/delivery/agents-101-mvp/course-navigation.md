# Agents 101 workbook navigation

Workbook: https://agents102.bosser.consulting/clients/acme-mvp/agents-101/

The workbook contains the teaching and exercise sequence. Follow the learner's current request. Course-supplied return links help the learner find the next section; they do not authorise starting the next activity.

Keep helping with revisions to the current work when asked. Do not preload later exercises, invent learner context, or turn this navigation file into a teacher persona.

Keep the learner's root instructions their own. Do not create a root CLAUDE.md or AGENTS.md for navigation. The learner creates their first root instructions in the Module 2 debrief.

Save position information only at prework/learning-position.md. Distinguish the current section, finished work, work in progress, and the next workbook link. A file existing does not prove the learner has finished the activity. When unsure, ask one question and wait.

Position information stays local. Do not transmit it or collect account details.
