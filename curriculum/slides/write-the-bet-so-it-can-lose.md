## Write the bet so it can lose
<!--slide:write-the-bet-so-it-can-lose-->

A product bet is a hypothesis about what will happen. Barry O'Reilly's hypothesis statement has three lines:

- **We believe** this capability
- **will result in** this outcome.
- **We will have confidence to proceed when** we see this measurable signal.

The third line does the work, and O'Reilly asks for it before anything is built, so nobody reads the result to fit the hope. His own example names a number and a window: five percent more customers who look at hotel images go on to book within 48 hours.

A signal that can only come back yes is not a test. Write one that could embarrass you, and agree on it before the agents start building.
