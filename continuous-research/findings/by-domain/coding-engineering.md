# Coding & Engineering — Agentic Deployment Findings

**Evidence level:** **Level 2** — no single claim in this file has been shown to clear the 10–20 independent-practitioner threshold. **Downgraded 2026-08-02 from a Level 3 badge reading *"convergence, 12+ independent signals"*, which did not survive an audit.** That count summed sources across *unrelated* claims — roughly three on the December phase shift, two on compound engineering, three or four on spec-is-the-moat — and the ladder's threshold is per-pattern, not per-file. A file-level convergence badge is also the wrong instrument regardless of arithmetic: it confers a level on every bullet beneath it, including bullets whose own evidence is a single case. **Read levels per finding below; where a heading and a bullet disagree, the bullet wins.** | **Last updated:** 2026-08-03

Coding is the domain where agents work best, and this is structural, not accidental. Five ingredients explain why: (1) executable verification (run the code, see if it works), (2) existing test suites, (3) tool access and iteration safety (git, CI/CD, sandboxes), (4) task decomposability (functions, modules, PRs), (5) rich context in code itself. These took decades to build. Other business domains lack most of them — which is why coding agents are well ahead, by a margin nobody has measured. (A "2-3 years" span stood here until 2026-08-03 — an invented number in editorial voice, removed.)

Two named practitioners report the December 2025 "phase shift" independently — Karpathy and Spotify, each first-hand and each cited below. **Willison was named here as a third and is not cited anywhere under this claim; removed 2026-08-02 rather than left standing as an uncited head-count.** Two reports is L2. *Converge* was the verb this paragraph used and it is not available at N=2 (`research-rules.md` — a vocabulary claim owes the same count a number owes): what the two describe is a discontinuity rather than gradual adoption, which is a shared *description*, not a measured convergence.
