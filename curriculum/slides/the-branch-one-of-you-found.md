## The branch one of you found is often worth most
<!--slide:the-branch-one-of-you-found-->

The branch one of you found is often the one worth the most. It is where someone heard a customer the others did not, or read a ticket nobody else opened.

Merge everyone's opportunity trees and that branch looks like noise beside the ones you all saw. Hand the merge to an agent and it gets worse: an agent asked for a summary gives you the middle, smoothly.

Keep the name of whoever found each branch on it. Treat a branch with one name as a question to answer, not a vote to lose.
