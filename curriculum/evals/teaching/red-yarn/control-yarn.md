# Control yarn: design for Agents 101

Yarn = controlling your agent. Strategy grid cells (core `strategy/content-strategy.md` § The four yarns). Model = AE101 verification: `ae101-yarn.md` (words) + structure (slide chains, exercise check steps, one growing figure, fixed phrases, a hole one module leaves for a later one).

## State (map 2026-11-13)
Control already appears in every module, in five vocabularies that never call each other: cold read (M1), plan/approve (M2), doubt (M3), residual / "I can't tell" (M4), judge / "touch the source" / known limit (M5), yardstick (M6), "somebody who answers for it" (M7), "checked like the first" (M8). Handle by count: **check** (noun) is the only word in all eight modules (1, 10, 8, 29, 42, 21, 4, 19). Push back = the gesture. Thin: M1 page, M2 framing (plan-first taught as cost control), M7 (control absent from page), M8 (control only in prompts + one late sentence).

## Handle and growth
Handle: **the check**. You check; push back is how. Meaning grows by what gets checked and who checks:
| M | What gets checked | Who checks | Grid |
|---|---|---|---|
| M1 | the agent's account of your own material | you, the one reader it cannot fool; a cold reader | evaluator who cannot be fooled |
| M2 | the plan, before files change | you approve; the agent proposes | plans first, acts on approval |
| M3 | the handoffs, and nothing checks the answer | nobody yet (the hole) | doubt = missing control |
| M4 | what it can reach; what you cannot tell | a check you run, a residual you sign | boundaries |
| M5 | each claim, against the source | a judge you benchmarked, with a known limit | a check touches the source |
| M6 | every output, with the yardstick fixed | the judge; you check the judge | you own the yardstick; would you let it act? |
| M7 | the copy in someone else's hands | a named person who answers for it | control after it leaves you |
| M8 | each agent your agent builds | the same checks as the first | each new agent checked like the first |

## Spine (structure, not added text)
1. **Fixed contrast, said once early, then pointed further out.** M1 `what-just-happened` "Read what comes back as a claim about the work, not a verdict on it." → M2 push-back slide (the summary vs the session) → M3 "The audit reads how your agents handed work to each other. It does not check whether the briefing is true." → M5 "The agent's report says what it intended, the file says what happened." → M6 "Nothing scores the judge." → M8 "The agent is auditing its own work."
2. **The hole, by hand → by the judge.** M2 "Watching where it bends is continuous improvement, done by hand." → M3 "Nothing here checks any of it" (hole stated) → M5 the judge built from the M3 briefing → M6 "the system absorbs the catches without your edits" (hole closed, same words reversed). AE101 analogue: checking loop "by hand for now" → "by your evals now".
3. **Propose, check, apply: one phrase from M2.** M2 Phase 4 approve/reject → M3 agent-that-takes-action "sends only after approval" → M4 gate (human approves) → M5 heading `## Propose, double-check, apply` → M6 actions callout → M8 extend-your-system "Show me the file before saving. After I approve". Same three verbs each time.
4. **The push-back slot.** Every module's Debrief is followed by a push-back slide. Keep the slot in every module and point it at that module's target (row "what gets checked" above). M4's push-back is an unheaded line; M7 has none.
5. **Hand-offs quote each other** (AE101 "how do you trust work you didn't watch?" → next module's first slide). Existing: M3 Bring "what's the worst thing it could do with that access?" → M4 Start; M4 Next "Can you trust what the agent says inside its scope?" → M5 Start; M6 Next → M7; M8.
6. **Figure.** Context yarn owns the `agent-picture` series (derived copies, one piece lit per module). Control's lit pieces: M4 boundary + ALLOWED? gate. Checks are deliberately absent from that figure (Antti 2026-09-24: no such gate inside the loop), so M5 has no checks piece to light; `grounded.md` `## In the full agent picture, this is the check` must agree with whatever the series draws.

## Rules for every edit
Reword existing sentences; no added sentence, slide, label, recap. Same length or shorter. Exercises and figures may change (Antti 2026-11-13) but go side by side to Antti before main. Prompt bodies need prompt-ok: untouched.
