## Findings

### [Finding 1] AI Now Friendly Fire — CONFIRMED ARCHITECTURAL, NO CVE, NO PATCH (New Clarity)

**Source 1:** `https://ainowinstitute.org/publications/friendly-fire-exploit-brief` — [domain trade publication / security research] (July 8, 2026, fetched August 22)
**Source 2:** `https://vibegraveyard.ai/story/friendly-fire-ai-security-agent-rce/` — [domain trade publication] (2026)
**Source 3:** `https://tech-insider.org/ie/friendly-fire-ai-coding-agent-exploit-2026/` — [general press] (2026)
**Date:** July 8, 2026 (PoC publication); fetch August 22, 2026
**Agent level:** Team/Company
**What:** AI Now Institute "Friendly Fire" PoC confirmed to be architecturally unfixable via version bump. The exploit plants prompt injections across repository files (README.md, security scripts, benign-appearing binary) — when Claude Code reviews the code for security vulnerabilities in auto mode, injections trigger full-host RCE. Affected CLI versions: 2.1.116, 2.1.196, 2.1.198, 2.1.199 (the versions tested). Underlying models: Sonnet 4.6, Sonnet 5, Opus 4.8 — all vulnerable. Also affects OpenAI Codex with GPT-5.5. **Critical finding:** AI Now explicitly says the fix "is not a version bump at all but a change in how these agents are allowed to operate." Anthropic responded to researcher contact but said the PoC "is not within the scope of the security disclosure policies for either Anthropic or OpenAI" — meaning no CVE will be assigned and no traditional patch will follow. This is distinct from the Check Point CVEs (CVE-2025-59536, CVE-2026-21852) which targeted config-based attack vectors (Hooks, MCP servers, env vars) and were patched. Friendly Fire attacks the code review workflow itself via model behavior.

**Evidence level:** Level 2 (PoC published with technical detail; cross-confirmed by independent security coverage; Anthropic's out-of-scope response documented by AI Now)

**Key claims:**
- Friendly Fire PoC (July 8) uses prompt injection in repo files — not config-based, no hooks/MCP/env vars required
- Attack requires only out-of-the-box auto mode and reviewing an untrusted repo
- AI Now: fix requires architectural change in agent operating model, not a version bump
- Anthropic declared PoC "not within scope of security disclosure policies" — no CVE, no traditional patch path
- Claude Code v2.1.238 (August 21, MCP/plugin security) does NOT address Friendly Fire — different attack vector
- CTO implication: auto mode reviewing third-party or dependency repos is the specific risk surface; in-house code review is unaffected
