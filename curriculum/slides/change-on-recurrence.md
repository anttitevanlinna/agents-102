## Change the rules on recurrence, not one miss
<!--slide:change-on-recurrence-->

An agent does not work the same way twice, so it gets the odd thing wrong even when nothing is broken. One wrong line in one digest is not yet a reason to change the rules.

W. Edwards Deming called reacting to every ordinary variation **tampering**: chasing it case by case adds noise of its own.

Wait for the same mistake to come back. The same kind of error in a second digest, or from a second source, is a signal. That is when the rule changes.

Watch for the easy win. After a bad night, the next one is usually better with no change at all. A rule written right after a miss can look like it worked when it did nothing.
