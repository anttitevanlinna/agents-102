## Leave it out of the plan and the agent decides
<!--slide:look-before-it-writes-->

What the plan leaves open, the agent decides halfway through, inside work already moving. A wrong call about which interviews count spreads into every page written after it.

So before the agent writes several pages, changes anything you care about, or starts work that builds on itself, ask for the plan first: a numbered list of what it will read, what it will write, and where. Ask it to wait for your go-ahead.

One correction to the plan can redirect every step after it.
