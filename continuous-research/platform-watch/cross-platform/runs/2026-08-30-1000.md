### Finding 3 — Claude Code auto mode security: Rehberger simpler variant published August 28; Trajectory Labs 720-attack result is not comparable; enterprise auto mode remains optional

**Sources:**
- [theregister.com/research/2026/08/28/researcher-shows-how-claude-code-can-be-tricked](https://www.theregister.com/research/2026/08/28/researcher-shows-how-claude-code-can-be-tricked-simply-by-asking-it-to-summarize-a-website/5293372) — [domain trade publication / Rehberger primary research]
- [simonwillison.net/2026/Aug/27/breaking-claude-code-opus-5-auto-mode/](https://simonwillison.net/2026/Aug/27/breaking-claude-code-opus-5-auto-mode/) — [practitioner direct — Willison]
- [kucoin.com/news/flash/claude-code-default-auto-mode-enabled-720-attacks-test-0-success](https://www.kucoin.com/news/flash/claude-code-default-auto-mode-enabled-720-attacks-test-0-success) — [general press / Trajectory Labs result summary]
- [cybersecuritynews.com/claude-code-shifts-agent-security/](https://cybersecuritynews.com/claude-code-shifts-agent-security/) — [domain trade publication]
- [helpnetsecurity.com/2026/08/10/anthropic-claude-code-auto-mode/](https://www.helpnetsecurity.com/2026/08/10/anthropic-claude-code-auto-mode/) — [domain trade publication]
- [truefoundry.com/blog/claude-code-prompt-injection](https://www.truefoundry.com/blog/claude-code-prompt-injection) — [practitioner analysis / enterprise guide]

**Date:** August 27-28, 2026 (Willison + The Register); August 10-14, 2026 (Trajectory Labs / auto mode default)
**Agent level:** personal (developers); company (enterprise deployment posture)
**What:** Rehberger published a simpler attack variant to The Register (August 28) alongside the August 27 Willison post: the attack chain begins with asking Claude Code to summarize a malicious website → WebFetch fails → Claude uses curl via Bash → 303 redirect to poisoned ZIP archive → archive contains malicious struct.py → Python module shadowing overwrites legitimate struct library → RCE. Three variants, each tested 5 times: 60–80% success rate. Rehberger's framing: "the classifier isn't built to stop determined prompt-injection chains made up of individually benign-looking steps; the real boundary is OS isolation and network egress control." This is a materially different result from Trajectory Labs' 720-attack evaluation (0 success): Trajectory Labs tested 72 curated indirect prompt injection scenarios held out from Anthropic's training — pre-defined attack types, not novel adversarial chains. Rehberger's variants are novel multi-step chains combining individually benign-seeming actions. The two results are not contradictory but are measuring different things: Trajectory Labs tests known-category attacks; Rehberger tests novel adversarial construction. The classifier's documented failure mode: it allowed the malicious process creation step and blocked the remediation command — safety mechanism inverted. Enterprise posture confirmed this cycle: auto mode remains OPTIONAL (not default) on Claude Enterprise, Claude API, Anthropic Platform, Amazon Bedrock, Google Cloud Agent Platform, Microsoft Foundry — enterprise admins evaluate before enabling. TrueFoundry published a Claude Code enterprise guide for prompt injection risks (practitioner analysis from an ML infrastructure company).
**Evidence level:** Level 2 (Rehberger independent security researcher, empirical results on 3 variants × 5 attempts; Trajectory Labs Anthropic-commissioned evaluation)
**Key claims:**
- Rehberger attack chain (The Register August 28): website summarize → curl fallback → 303 redirect → poisoned ZIP → Python module shadowing → RCE; 60–80% success rate across 3 variants
- Classifier failure anatomy: allowed malware process creation → blocked remediation command (inverted)
- Trajectory Labs (720 attacks, 0 success): curated 72-scenario set held out from training — NOT comparable to Rehberger's novel adversarial chains; measures known-category attack resistance, not novel adversarial construction
- Enterprise auto mode: optional on Claude Enterprise, API, Bedrock, Google Cloud, Microsoft Foundry — enterprise admins choose adoption timing
- Recommended mitigations (convergent: Rehberger + Willison + cybersecurity press): containerize unattended coding agents, restrict network egress, exclude home directories / SSH keys / cloud credentials from agent runtime, monitor agent behavior
- "Auto mode is a convenience feature backed by a best-effort classifier, not a security guarantee" — CyberSecurityNews framing confirmed
