## The branch only one of you found
<!--slide:the-branch-one-of-you-found-->

Merge four people's opportunity trees: the branches everyone saw grow thick, and the branch one person saw looks like noise. Hand the merge to an agent and it gets worse. An agent asked for a summary gives you the middle, smoothly.

The branch one of you found is often the one worth the most. It is where someone heard a customer the others did not, or read a ticket nobody else opened.

So sketch alone first, then merge. Keep the name of whoever found each branch on it. Treat a branch with one name as a question to answer, not a vote to lose.
