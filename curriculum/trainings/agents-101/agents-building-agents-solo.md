# Agents Building Agents

## Big Idea

An agent can build the agent someone else needs. That is how you and the people around you learn faster.

## Prework

**Bring `module-6/trigger.md`, your Module 2 agent and your Module 5 judge.** The trigger helps you name a person, the judge checks what an agent builds, and the Module 2 agent gets rewritten at the end.

## What You'll Learn

After this module, you will be able to:

- **Have** agents build agents
- **Improve** an agent with an agent

## Start here

Start a fresh session or task at `~/Documents/agents-101/`.

Your system works for you because it reads your memory. Who is one person who could use what it makes, and what would they need if your memory stayed with you?

[Exercise: Build an agent for someone else](exercises/build-for-the-gap.md)

[Lecture: Where is this all going?](lectures/where-is-this-all-going.md)

## Debrief

Five minutes. Your agent improves your agent. It compares your Module 2 agent with the one it built today, rewrites the Module 2 agent in place so it would work for someone without your memory, and reports what changed.

{{prompt:a101-solo-debrief-works-without-me}}

## Give it to them

After this module, show your person what the new agent makes, or ask them the question in `module-7/person.md`. Their answer tells you which agent to build next.

## Key Concepts

- Describe an agent and an agent builds it, then rebuilds it from what the judge finds.
- The gap someone else hits is the brief for the next agent.
- Your agent can improve your agent.
- Each agent built makes the next one quicker. That is how you and the people around you learn faster.

## Next

Name your next gap. Describe the agent for it. An agent builds it; you test it on your own work before it reaches anyone else's.

Every agent your agents build or improve makes the next one quicker to build. How far this goes depends on how fast you and the people around you learn. When a whole team does it together, an organisation learns.

We could have spent this course building you one impressive agent. It would have demoed well and been the wrong thing to give you. Everyone wants their hundred agents; the one that matters in six months is one nobody has thought of yet. What you take out of here is the ability to build it.

Sharing agents across a team and building a strategy with everyone's agents together is the team edition of this course.

One question to carry out of the course: what is going to be the next hard part about agents?
