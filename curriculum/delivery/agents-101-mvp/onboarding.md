<h1 id="start-learning">Welcome to Agents 101</h1>


You can ask Claude a question. You can also ask it to make a file you can use. Let’s try that with something small before we bring any work into it. First, a game. Later, a briefing from your calendar.

## Pause learning

If you’ve added the course files, copy and send the request below before you close Claude. Claude saves your place in the `agents-101` folder. If you haven’t added the course files yet, bookmark the section you’re on.

**Prompt** Cowork

```text
Help me pause Agents 101 so I can resume later.

Use `prework/course-navigation.md` to save my place before we stop.
```

## Resume learning

If Claude saved your place, open a new conversation in Claude Desktop and select your `agents-101` folder again. Copy and send the request below. If you bookmarked a section, open that bookmark.

**Prompt** Cowork

```text
Help me resume Agents 101.

Read `prework/course-navigation.md` and help me find my place in the workbook.
```
