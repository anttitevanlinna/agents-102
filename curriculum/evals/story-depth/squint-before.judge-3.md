# Squint test — baseline (Agents 101 skeleton)

## 1. Big learnings

- Context is the lever that changes what an agent produces — "Context is King," "Context isn't only about countries"
- Retro/iteration is a discipline, not an afterthought — "Iterate and Learn," "What just happened"
- Compounding is a real mechanism, not a buzzword, and has a cause — "Compounding," "Two words, held together," "Why the sharpening happens"
- Memory has to be curated and built under a plan, not dumped in — "Build your challenge memory," "Curate the source plan," "Build the memory under a plan," "Review the plan, then have the memory audit itself"
- Big systems get split into multiple specialized agents — "When to split an agent (and how)," "Three retrievers, one curator," "Three minds, one synthesis"
- Agents get stuck and that's a distinct, nameable failure mode — "Debugging Stuck Agents"
- Risk/security is a practiced discipline you author and package, not a checklist you inherit — "The discipline of risk," "Run and package a security skill," "Audit your agent"
- LLMs fabricate, and grounding them is harder than it looks — "The Missing Check," "Why the LLM fabricates," "Why grounding fails even when the facts are in context," "Grounded, and four candidates to measure"
- Judgment can be turned into a judge (an eval) — "Module 5 turned judgment into a judge," "Evals as Steering"
- Eval loops can run unattended, which changes the human's job — "The eval loop runs itself," "The New Human Role in the Loop," "The human does not disappear"
- Sharing work with a team is a design choice with a shape to pick, not a default — "Pick the sharing shape," "Interview for the job and pick a candidate," "Design the sharing plan"
- Agents can build agents — a flywheel, named as such — "Agents Building Agents (The Flywheel)," "Watch an agent build an agent"
- Multi-agent deliberation can produce a group decision a human still signs off on — "Agent Proposal Forum, diagnose and guide," "Final synthesis and the human decision"

## 2. Governors

- Name the framework before applying it, and tune it to fit — "Name the framework and tune it" (M1)
- Bound what you let the agent read before ingesting a big source set — "Keep the heavy reads under control" (M2)
- Plan your sources before you curate/ingest them — "Curate the source plan" (M2)
- Keep the main session blind to the answer key before running a benchmark — "Keep the main session blind" (M5)
- Separate prototype from production before trusting an agent's action — "Separate prototype from production" (M4)
- Escalate to a person once judgment runs out, rather than letting the agent decide — "Escalate to a person when judgment runs out" (M4)
- Find the absorption bottleneck before designing how work gets shared — "Find the absorption bottleneck" (M7)
