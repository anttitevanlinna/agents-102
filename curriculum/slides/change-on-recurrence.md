## Change the rules on recurrence, not one miss
<!--slide:change-on-recurrence-->

An agent varies from run to run, so it gets the odd thing wrong even when nothing is broken. One wrong line in one digest is worth a note. It is not yet a reason to change the rules.

W. Edwards Deming called reacting to every ordinary variation **tampering**: chasing it case by case adds noise of its own.

Wait for the same mistake to come back. The same kind of error in a second digest, or from a second source, is a signal. That is when the note becomes a rule.

After a bad night, the next one is usually better with no change at all, so a rule written right after a miss can look like it worked when it did nothing.
