## Three layers, one folder
<!--slide:three-layers-one-folder-->

Three layers, separate on purpose. Raw sources: the untouched originals you dropped in. Memory: topic pages the agent maintains and sharpens. Rules file: the instructions the agent reads so every update follows the same pattern.

Sharpen the memory, never the sources, or you lose the evidence.
