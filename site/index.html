Build agents that do real work for you

Agents 101 is a free course you take on your own, in Claude Desktop, on your own files. Your first message makes a game. Seven modules later you have agents that remember, check their own work and improve other agents.

Start with prework About 50 minutes. You need a paid Claude plan.

How it works

Keep the handbook open beside Claude

You learn by doing the work, one short step at a time.

  1. Read the stepEach step says what you are about to make and why it matters.
  2. Type what the card saysCopy the message into Claude and press Send. No code.
  3. Check the replyThe handbook tells you what to look for, and what to ask when it is missing.

Type in Claude Desktop

Make me a Snake game and link to the file here.

In Claude's reply

Look under your message. The link to the Snake game is the file Claude made for you. If you only get a description, ask "Can you attach the game?"

The course

Prework and seven modules

Each module builds on what you made in the one before. Take a module a week, or a few in a weekend.

  1. 0

    Prework

    Make a game from one message, keep it in a folder, then get a summary of your week in meetings.

    50 min
  2. 1

    Getting Going

    What you give the agent shapes what comes back: your profile, your rules, your judgement on the result.

    • Engineer context
    • Write rules for an agent
    • Judge agent output
    80 min
  3. 2

    Building Agent Systems

    A system remembers and grows around the one thing you need to make progress on. Chat can't.

    • Create agent memory
    • Create an agent
    • Schedule an agent
    • Review an agent's plan
    90 min
  4. 3

    Multi-Agent Systems

    Several agents split one problem, work in parallel and hand off through shared files.

    • Orchestrate multiple agents
    • Split work across agents
    • Debug agent handoffs
    95 min
  5. 4

    Security

    You can't tell if your agent is safe from its output. Run a check instead of waiting for certainty.

    • Audit an agent for security
    • Write a skill
    • Mitigate agent risk
    105 min
  6. 5

    Catching Hallucinations

    Where your agent can't reach a source, it fills the gap: confident, plausible, wrong. You make the gap visible.

    • Detect hallucinations
    • Benchmark AI checks
    • Build a judge
    95 min
  7. 6

    Evaluations

    Put your judge in a loop and the work improves round after round, while you do something else.

    • Run an eval loop
    • Steer agents with feedback
    85 min
  8. 7

    Agents Building Agents

    Your agent can improve your agent. That is how you learn faster than the tools change.

    • Have agents build agents
    • Improve an agent with an agent
    60 min

About 11 hours in all, prework included.

What you need

  • A paid Claude plan. Pro, the lowest paid tier, is enough.
  • Claude Desktop on a Mac or Windows computer.
  • A folder of your own. The prework shows you how to make it.
  • Your work calendar, if you can. A screenshot of your week works too.
  • No coding. You write plain sentences.

What you keep

  • Everything you build stays in that folder on your computer: your agent memory, your agents, your skills and your checks.
  • The work they do on your files is yours too.
