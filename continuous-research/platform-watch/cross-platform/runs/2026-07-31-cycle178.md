### [Finding 3] Antigravity Agent API docs — confirmed capabilities and limitations; enterprise tier still "coming months"

**Source:** https://ai.google.dev/gemini-api/docs/antigravity-agent — [vendor documentation] (July 31, 2026)

**Date:** July 31, 2026
**Agent level:** personal → team (Preview only; enterprise tier pending)
**What:** Antigravity Agent is "a general-purpose managed agent on the Gemini API" operating in a secure Linux sandbox. Technical foundation: **runs Gemini 3.6 Flash by default** (configurable to 3.5 Flash or 3.5 Flash-Lite via `agent_config`). "Uses the same harness as the Antigravity IDE."

**Capabilities:** Bash/Python/Node.js execution, file management (read/write/edit/search/list), web search and URL fetching, MCP server integration (custom functions/external APIs), multimodal (text + images), multi-turn with context compaction at ~135k tokens.

**Cost:** Pay-as-you-go on underlying Gemini tokens + tool usage. Typical range: $0.25–$5 per interaction depending on complexity. 50–70% of input tokens typically cached.

**Explicit limitations from docs:** No structured outputs, no file search, no computer use, no Google Maps. Enterprise deployment and multi-agent management frameworks: "coming months."

**Evidence level:** L0 (vendor documentation — capability listing; zero independent deployment reports)
**Key claims:**
- Model: Gemini 3.6 Flash (not 3.5 Pro — dependency on delayed model is bypassed)
- Preview tier, available via Interactions API and Google AI Studio for free and paid projects
- MCP server integration confirmed — the critical enterprise connectivity mechanism is present
- "Enterprise coming months" = enterprise deployment evidence not available yet; planning horizon unclear
- Context compaction at 135k tokens is a hard limit for very long multi-turn agentic sessions
- The "same harness as Antigravity IDE" suggests architectural consistency between developer-IDE and API-managed-agent; reduces integration translation cost
