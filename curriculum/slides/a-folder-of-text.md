## The team's memory is a folder of text, on purpose
<!--slide:a-folder-of-text-->

The insight memory an agent keeps for your team is a folder of plain text files. No database, no special tool, no paid tier. The agent's own instructions are a text file too.

That looks like a limitation. It isn't. Language models are strongest at reading and writing text. Store what you know as text, and the agent reads it by reading and updates it by writing. Nothing sits between the model and what it does best.

It also means the whole team can open it. The designer reads what the agent believes about your customers, the product owner corrects a line, and the folder moves with you to whatever tool comes next.
