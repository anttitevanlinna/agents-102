# Learning coding agents: practitioner methods OODA Cycle — 2026-09-06 09:30

**Focus area:** How practitioners turn coding-agent sessions, traces, and human corrections into durable knowledge for later runs.
**Research mode:** Practitioner deep-dive.
**Why this focus:** A user is considering a training module in which a bug-handling agent harvests rules from current and historical sessions, accepts human judgment, compounds the result, and is rerun. This is a Tier 0 question, and the current knowledge base did not establish whether the full chain exists in practice.

## Findings

### Every has the closest coding-specific capture and return edge

**Source:** https://github.com/EveryInc/compound-engineering-plugin/blob/b159e1fa4c70efa995742269d38269bcc7524dd2/docs/guides/ce-compound.md — [practitioner direct]
**Date:** Current implementation checked 2026-09-06
**Agent level:** Team
**What:** `ce-compound` can inspect current and selected historical sessions from multiple coding-agent surfaces, extract attempted approaches, errors, decisions, and user corrections, then write one verified learning under `docs/solutions/`. Planning and ideation search that store later. A human can invoke the compound step; configured automatic mode may write qualifying learnings without per-item approval.
**Evidence level:** L2 single-team mechanism; no controlled cross-run effectiveness measure.
**Key claims:** The store is versioned and discoverable; historical sessions are an input; high-overlap findings update a canonical learning; future planning searches the store.

### Human-first trace review supplies the missing judgment gate

**Source:** https://hamel.dev/blog/posts/evals-faq/how-many-examples-do-i-need-for-an-eval.html — [practitioner direct]
**Date:** 2026-09-01
**Agent level:** Team
**What:** Hamel Husain and Shreya Shankar start trace analysis with human free-text judgment, let an agent organize and extend the emerging failure taxonomy only after the human has established examples, and require accept or dismiss decisions on suggestions. Confirmed failures become repeatable eval cases rather than free-floating memory.
**Evidence level:** L1 current method; no named coding-team outcome in this source.
**Key claims:** The initial pass remains manual to avoid bias; agent suggestions stay separate from human annotations; later evaluators are checked against held-out human labels.

### Executable sensors are a stronger destination than prose for objective rules

**Source:** https://www.martinfowler.com/articles/sensors-for-coding-agents.html — [practitioner direct]
**Date:** 2026-05-27
**Agent level:** Team
**What:** Birgitta Böckeler promotes known agent failure modes into deterministic checks with corrective error messages, runs them during coding and again in CI, and records sensor history. The reported outcome is improved review experience and several in-session self-corrections, not a measured cross-run delta.
**Evidence level:** L2 exploratory single case.
**Key claims:** Objective guidance can become executable feedback; sensor history can expose rules that never fire or overwhelm the agent.

## What I Looked For But Did Not Find

No named practitioner in this sweep demonstrated the full chain: session and trace ingestion → candidate-rule harvest → explicit human promotion → durable agent-readable store → measured improvement on a comparable later coding task. Every has the strongest capture and reuse mechanism; Husain and Shankar have the strongest human-approved trace-to-eval method; Böckeler has the strongest executable-rule destination. Joining them is an inference, not a documented standard.

## Orientation

The proposed training module is timely but ahead of established practice. Teach it as a controlled experiment: the system has externalized a learning only when a fresh run can discover and use the accepted artifact; it has improved only when the rerun beats a no-rule baseline without new regressions.
