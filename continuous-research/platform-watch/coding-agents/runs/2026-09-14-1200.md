### Finding 4: GitSpawn — NEW supply-chain attack class affecting 7 coding agents (Sep 1)

**Source:** https://www.manifold.security/blog/ai-coding-agents-git-hijack — [practitioner analysis — security research firm]
**Secondary:** https://thehackernews.com/2026/09/malicious-git-configs-can-make-claude.html — [domain trade publication]
**Date:** September 1, 2026 (Manifold blog); September 2, 2026 (Hacker News)
**What:** Manifold Security (Francisco Rosales, Offensive Security Engineer) disclosed 8 code-execution findings across 7 AI coding agents via a single vector: malicious `.git/config` files using the `core.fsmonitor` Git setting. When an agent runs `git status` to orient itself (standard behavior), Git executes the `core.fsmonitor` value as a shell command — arbitrary code execution as the developer, outside the sandbox, with no approval prompt. The vector survives archives, shared drives, synced folders, and dev containers. Standard `git clone` does NOT copy source `.git/config`, limiting main infection vector to poisoned repositories that developers directly download or receive.
**Evidence level:** Level 2 (named security research firm, named researcher, specific CVEs, verifiable patch status, independent third-party coverage)
**Key claims — patch status at disclosure (Sep 1):**

| Agent | Status | Version | CVE |
|---|---|---|---|
| Goose | Patched | 1.44.0+ | CVE-2026-72718 (CVSS 7.0) |
| Codex CLI | Patched | 0.131.0+ | CVE-2026-19592 |
| Codex Desktop (macOS) | Patched | 26.519.22136 | CVE-2026-19592 |
| Claude Code (fsmonitor path) | Patched | 2.1.196+ | CVE-2026-55607 |
| Cursor | Patched | 3.0.0+ | — |
| Hermes Agent | Unpatched | 0.21.0 | CVE-2026-71963 (VulnCheck, not vendor-confirmed) |
| Qwen Code | Unpatched | 0.22.3 | — |
| Grok Build | Unpatched | 1.0.13 | — |
| **Claude Code (ultrareview path)** | **Unpatched** | **2.1.252** | — |

- Claude Code has TWO findings: one patched (fsmonitor path, CVE-2026-55607, reported Jun 26), one STILL UNPATCHED (ultrareview path, reported Jul 15, still live as of 2.1.252)
- On Claude Code and Hermes: payload fires BEFORE workspace-trust prompt is accepted
- On Qwen Code: payload fires before user has authenticated
- No exploitation in the wild reported; not in CISA KEV catalog as of early September 2026
- Disclosure timeline: all reports between Jun 26 – Jul 20; publication Sep 1 (following 60-90 day responsible disclosure window)

**New attack class significance:** This is the first publicly documented systematic evaluation of `core.fsmonitor` as a coding-agent attack vector. The implication for teams using Loop Engineering (multiple concurrent agent sessions): each session that runs `git status` on an untrusted repo is a potential execution vector. Existing enterprise security posture (sandbox, VPC isolation) does not neutralize this if agents have shell access to a malicious config.
