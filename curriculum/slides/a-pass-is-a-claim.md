## A pass is a claim about the check
<!--slide:a-pass-is-a-claim-->

When the agent's check says "good", it means it saw nothing wrong. It does not mean the work is good. Three different things look identical from outside: it judges differently from you, the work was shaped to pass, or this run happened to go well.

Each has its own answer. Keep some of your criteria where the agent never sees them. Run the same task more than once before you trust it.

Asking the same agent twice in the same conversation is not a second opinion.
