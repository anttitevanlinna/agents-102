# Squint test — a101-skeleton-to-be.md

## 1. Big learnings

- Context isn't given, it's constructed — the agent rereads everything, and what you feed it defines what it knows. → "It reads the whole conversation every time," "Context is whatever you tell it"
- A system's report on itself is a hypothesis, not a verified result. → "The report is a hypothesis, not a result"
- Agents amplify what you bring to them, good or bad. → "It amplifies what you bring"
- Systems compound by being edited over time, not by being cleverly designed once. → "It gets better by being edited, not by being clever"
- What isn't written down can't be used by the system. → "What you haven't written down, it can't use"
- Fixing an output without fixing the rule that allowed it is incomplete. → "Fix the output, then fix the rule that let it through"
- Default to not splitting an agent; split only when parts genuinely can't be one. → "Start with don't," "Splitting earns its keep when they can't be one"
- A single synthesizer drifts toward bland averages; multiple stances counter that. → "Three stances beat one summarizer," "Left alone, the synthesizer averages to beige"
- Debug by diagnosing first, not repairing first. → "Diagnose before repair"
- The old certainty about how systems behave doesn't hold anymore. → "Certainty is a fantasy you inherited"
- Agent security breaks the human-employee trust model — no employee treats every document as an instruction, but agents can. → "No employee reads every document as an instruction"
- The strongest mitigation is avoiding exposure altogether. → "The best mitigation is the door you don't open"
- Grounded output assumes a checkable truth exists. → "There is truth out there"
- Being mostly right repeatedly still compounds into being wrong. → "Mostly right, ten times over, is mostly wrong"
- Fluent confidence is not verification. → "'Are you sure?' is another fluent answer"
- Evals/judges have their own limits, and a rewritable yardstick isn't a yardstick. → "The judge names its own limit," "A yardstick you rewrite is not a yardstick"
- Evals do two different jobs: protecting a floor and raising a ceiling. → "Groundedness protects the floor," "Steering raises the ceiling"
- As systems improve, human attention on them naturally drops. → "The better it gets, the less you watch"
- The human role shifts up a level rather than vanishing. → "The human moves one level up"
- Giving people access to a tool doesn't mean they absorb how to use it. → "Access is not absorption," "Access is easy; absorption is scarce"
- People only absorb what they already half-understand. → "People absorb what they already half know"
- Tools that build tools compound their advantage. → "The tool that builds tools compounds"

## 2. Governors

- Before letting an agent act irreversibly, ask whether you'd let it send the mail. → "Would you let it send the mail?"
- Before trusting an eval/report, ask when you last read one yourself. → "When did you last read one of these yourself?"
- Before committing to a course, ask what would change your mind. → "What would change our mind?"
- Before repairing a stuck agent, diagnose first. → "Diagnose before repair"
- Before splitting an agent into multiple, start from "don't." → "Start with don't"
- Give yourself permission to say "I can't tell" instead of forcing a verdict. → "'I can't tell' is a real answer"
