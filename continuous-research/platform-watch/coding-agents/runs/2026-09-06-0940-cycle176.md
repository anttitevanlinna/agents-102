## Findings

### Every closes the knowledge return edge but does not measure the next task

**Source:** https://github.com/EveryInc/compound-engineering-plugin/blob/b159e1fa4c70efa995742269d38269bcc7524dd2/skills/ce-compound/SKILL.md — [practitioner direct]

**Agent level:** Team
**What:** The current implementation mines the live conversation and selected prior sessions, produces one grounded Markdown learning, deduplicates it against the store, and makes later planning search that store. Targeted local tests passed 23/23, but they validate artifact contracts and refresh behavior rather than later-task quality.
**Evidence level:** L2 single-team implementation.
**Key claims:** Capture, durable storage, maintenance, and later retrieval are wired; per-learning human acceptance and controlled before/after measurement are not.

### ReasoningBank measures automatic trace-to-memory reuse without a human gate

**Source:** https://github.com/google-research/reasoning-bank/blob/ed80611788292ea739f1effd31f16c53823b8a0d/third_party/src/minisweagent/run/extra/swebench.py — [academic/research]
**Date:** Current commit checked 2026-09-06
**Agent level:** Personal
**What:** The SWE-bench runner saves the agent trajectory, self-judges success or failure, distills up to three generalized memory items into JSONL, retrieves the most similar prior task, and passes its memory into the next run. The authors report 38.8% versus 34.2% without memory for Gemini 2.5 Flash and 57.4% versus 54.0% for Gemini 2.5 Pro.
**Evidence level:** L2 author-run multi-benchmark experiment.
**Key claims:** The return edge and outcome comparison are executable; correctness depends on an LLM judge; there is no human promotion, staleness review, or per-memory rollback.

### Ruflo DREAM shows a stronger promotion ledger for code changes

**Source:** https://github.com/ruvnet/ruflo/blob/277c7bc03ad192eef6d6f57e59ab7bab69a5728d/docs/dream-cycle/LEDGER.md — [practitioner direct]
**Date:** Commit checked 2026-09-05
**Agent level:** Team
**What:** DREAM records frozen hypotheses, issues, candidate PRs, baseline/candidate evidence, human rejection or remediation, merge decisions, and later-run state. A reviewed change was rejected for inadequate evidence, remediated, and then merged. The loop improves code rather than turning session corrections into behavioral rules, and the external orchestrator is not published.
**Evidence level:** L2 repeated single-project mechanism.
**Key claims:** Human promotion can be a real gate; rejected and zombie work remain visible; component metrics do not prove that the coding agent improves across nights.

### Current implementations document their own memory failure modes

**Source:** https://github.com/EveryInc/compound-engineering-plugin/commit/415181d3c56a6ef63415bbe9e328c9a26cad04b8 — [practitioner direct]
**Date:** 2026-09-03
**Agent level:** Team
**What:** One day after tightening its durable-learning bar, Every culled or sharply shortened 110 files, totaling 8,576 deletions. Ruflo's earlier DREAM ledger records 80 nightly research issues producing only four shipped changes, while an inspected ReasoningBank derivative had unwired hooks and failing checked-in suites.
**Evidence level:** L2 counter-evidence from current repositories.
**Key claims:** Stores can over-accumulate; an unwired return edge can look complete in documentation; agent-generated work can become durable zombie work rather than learning.

## What I Looked For But Did Not Find

No inspected repository implemented the entire chain. HumanLayer's named ACE repository was essays rather than software. Every lacked a required candidate accept/reject gate and later-task measure; ReasoningBank lacked human judgment and robust lifecycle controls; Ruflo had strong code-promotion governance but did not harvest human corrections into rules.

## Orientation

The missing artifact is a **promotion ledger**, not another memory directory. Preserve the source trace and human rationale, keep rejected candidates visible, record where an accepted rule is loaded, and compare a fresh run against a fixed yardstick. Artifact validity and retrieval success alone are not evidence of improvement.
