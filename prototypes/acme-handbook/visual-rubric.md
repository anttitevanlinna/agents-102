## Historical rubric and prototype

Use this rubric on the rendered ACME self-study handbook. AAA is the critic’s design verdict for this experience. Record accessibility checks individually.

| Dimension | What earns 4 |
| --- | --- |
| Orientation and hierarchy | At the bare URL and Start link, the learner can locate the current task and its first action in the initial laptop viewport. At later lessons the heading and course position are immediately legible. |
| Action and result | The exact sentence to type, an instruction to follow, an optional demonstration and a result to look for have distinguishable treatments. A later copyable prompt communicates its purpose and gives feedback. |
| Navigation and return | On returning from Claude, the learner can locate Keep my game, land on its heading, and carry on to the folder and calendar steps. Local position stays accurate after clicking, scrolling and keyboard navigation. |
| Typography and layout | The page has a recognizable character, a clear type scale, comfortable line lengths and deliberate spacing. Setup controls, demonstrations and later exercises share that visual language at both desktop sizes. |
| Operability | Keyboard users can see and use links, disclosures, OS selection and Copy. Both OS variants remain readable and the document handles the tested viewports without clipped essential content. |

Score each dimension from 0 to 4. **0** means absent or broken. **1** requires searching or guessing. **2** is usable with a material ambiguity. **3** is fluent with a localized imperfection. **4** is exemplary in all applicable states.

**AAA requires at least 19/20, every dimension at least 3, every gate below passing, and explicit approval from an independent visual critic.** Record the state, visible element and learner consequence for each deduction. Keep these criteria fixed while iterating.

### Earlier review record

The independent critic scored the published baseline **11/20**. Orientation 2, action and result 2, navigation and return 2, typography and layout 3, operability 2. The cover and welcome competed, the first request resembled a quotation, and the course-wide controls outweighed the local map.

| Desktop version | Orientation | Action and result | Navigation and return | Typography and layout | Operability | Verdict |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| Published baseline | 2 | 2 | 2 | 3 | 2 | 11/20 |
| First prototype | 4 | 4 | 3 | 1 | 4 | 16/20, exercise gate failed |
| Revised prototype | 4 | 4 | 4 | 3 | 4 | **19/20, AAA approved by the independent critic** |

On the first prototype, Keep my game landed with the previous lesson’s last line above the heading. At 1440 pixels, the first Module 1 prompt had only 100 pixels for its text. Its filename broke across lines. On the revised prototype, the clicked heading opens at the top of the reading area, the course map highlights it, and the prompt spans 860 pixels.

The critic checked both entry points in Chrome at 1280 × 800 and 1440 × 900. The return link, position indicator, Mac and Windows instructions, walkthrough disclosure, calendar, Module 1 and Copy feedback passed. Keyboard activation worked and neither viewport scrolled horizontally. Essential visible text in the five inspected states met the contrast cutoffs. Sample focus contrast measured 7.65:1 in the navigation, 6.10:1 on the page and 7.30:1 in the exercise. The sole deduction was a line wrap at 1280 pixels where the Mac folder instructions put the `+` control on a line by itself.
