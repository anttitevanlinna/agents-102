## A system remembers and runs; either alone is a toy
<!--slide:it-remembers-and-it-runs-->

Two things together turn a chat into a system:

- It remembers. Pages on disk, not a conversation that resets.
- It runs on its own, from instructions in a file it reads each time it starts, not because someone retyped the request.

Either alone is a toy. A folder of notes with no agent is a folder. An agent with no notes is a chat. Together they get better the more you feed them.

An agent that reads the team's insight pages each night, adds the day's new tickets and interviews, and leaves sharper pages by morning is the pair at work.
