## Hunt for buried gold

Moves are declared well across AE101. **Priors, mechanisms and why-it-works claims are not.** Those are a different species from a move, and a sweep shaped around *"which beat fails to name its move"* structurally cannot see them: a move is *do X*, a prior is *assume Y*, a mechanism is *it works because Z*. The recurring shape is not a missing sentence. The sentence exists, is correct, is well written, and sits somewhere with no weight: a fourth bullet, an item in an enumeration whose point is something else, link anchor text, or a supplementary that never reaches the deck.

Twenty-one candidates were adjudicated against the corpus; what stands is below. Supplementary and reference pages do not reach the composed Slides deck (`check_slides.md §10`), so a beat's checklist can be in-deck while the reason it is not arbitrary sits in a linked page. Settle each such case on whether the reason changes what the student does, not on where the page happens to live.

### Promote — four bullet- or clause-level edits, zero minutes added

All four land inside existing leaves; no leaf `**Time:**` line and no `- **Transitions:**` line moves, so `scripts/calculate-time.js --check` stays green. The real cost is 30–45 trainer-pace seconds across all four, which is invisible to the script and audible in the room. If only an hour is available, take them in the order 3, 4, 1.

1. **Compounding includes deletion.** [spot-gaps-build-the-loop.md:38](../../exercises/spot-gaps-build-the-loop.md) says rules files have a half-life: adding rules is only half; subtracting dead ones is the other half. The general loop is *add → sharpen → delete*; otherwise the context system compounds noise along with learning. [theory-plan.md](../../../theory-plan.md) § *The social layer* holds the second driver design-side: rules decay socially, not only factually. Ronacher's [Things That Didn't Work](https://lucumr.pocoo.org/2025/7/30/things-that-didnt-work/) supplies the same move for automation, and joins here rather than standing alone: record what was tried and the acceptance variance, then remove the dead helper so a later agent does not inherit or rediscover it. **Action:** extend M6 `## Key Concepts` bullet 6. The move is already enacted with its own slide, LO and leap test; only the generalisation is missing from the reminder slot.
2. **Parallelism has a topology, not just a count.** The strongest rule sits in optional [workflow-composition-lineages.md](trainings/agentic-engineering-101/supplementary/workflow-composition-lineages.md): Cognition's parallel writers conflicted; a single writer with advisor/reviewer agents held. Parallelise independent reads, investigations and reviews; serialise coupled writes and shared semantic decisions. Parallelism pays only when the gain beats coordination, conflict and merge cost. The core course's one parallel-sessions line is [learn-from-the-test.md:36](learn-from-the-test.md), *"a session you don't babysit can run beside another"*, permission without a shape. **Action:** one clause in the M5 module § *Hold the worry beside the artefact*, before students equate more agents with more throughput.
3. **The diff and the transcript are two different evidence layers.** [diagnose-and-resend.md:28](../../exercises/diagnose-and-resend.md) says the git history tells *what* the agent did while the transcript tells *how* it got there, drift and dead-ends included. [claude-code-for-engineers.md:322](trainings/agentic-engineering-101/reference/claude-code-for-engineers.md) states the general form; [what-packaging-is.md:237](../../lectures/what-packaging-is.md) has the agent using both in one breath. Outcome evidence without process evidence misses the mechanism of failure; process evidence without the diff misses what actually shipped. **Action:** new bullet in M5 `## Key Concepts`, at 48w/4b the emptiest destination in the set and the widest-reaching promotion available.
4. **Every check has a latency budget.** Optional [how-the-best-do-ci-cd.md:43](trainings/agentic-engineering-101/supplementary/how-the-best-do-ci-cd.md) § *Eval latency is part of the loop* splits the fast lane from the slow: cheap deterministic checks run in seconds and verify the agent's next move; judges and gates run in minutes, in the background. Core M5/M6 names verifiers, judges and gates but leaves them sounding interchangeable. **Action:** new bullet on [the-loop-has-a-name.md](../../lectures/the-loop-has-a-name.md) § *One primitive, placed wherever there's a bar* (92w/2b, 118 words of headroom) — the slide's whole subject is placement, and latency is the placement axis it lacks. Seconds inline, minutes asynchronously, expensive judgment at a named gate.

### Needs Antti's call

- **Cherny's recurrence threshold, judgment → automation.** Cherny's reported Meta practice was to log repeat review comments and write a lint rule once the pattern recurred three or four times ([Orosz interview](https://newsletter.pragmaticengineer.com/p/building-claude-code-with-boris-cherny)). AE101 teaches compounding and verifiers but not the promotion threshold. **Blocked because** it contradicts a printed figure caption; lands in M2 [how-instructions-grow.md](../../lectures/how-instructions-grow.md) only if that caption is reversed.
- **Willison's comprehension gate at handoff** — the strongest of the practitioner set, card drafted. [Understand to participate](https://simonwillison.net/2026/Jul/2/understand-to-participate/) names cognitive debt: as the agent's implementation outruns the human's model of it, the human loses the concepts needed to steer what comes next; passing checks does not repay that debt. **Destination:** M3 [earn-the-trust.md](earn-the-trust.md), the clear-the-session beat.
- **Willison's rule-to-judgment ladder** — encode invariants, constraints and evidence requirements; delegate observable, reversible choices; remove rules that no longer bind. Theory-rewrite scope, not a card.

### Tensions the theory rewrite must preserve

These are not inconsistencies to smooth away. Each pair identifies a boundary the course needs to teach.

- **Parallel generation versus accountable absorption.** Klaassen's direction increases concurrent generation; Ronacher's direction limits starts by trustworthy review capacity. Both can be true because bottlenecks migrate. Available agent slots measure production capacity; acceptable WIP is governed by how much returned work the verification and review system can absorb. **Action:** teach concurrency and WIP as different quantities, with a decision rule for when another stream helps and when it only lengthens the unread queue.
- **Encoded rules versus delegated judgment.** AE101 teaches durable instructions and deterministic checks; Willison shows the value of letting a capable agent choose reversible tactics inside explicit boundaries. The mature system is neither rule-free nor maximally prescribed: encode invariants, constraints and evidence requirements; delegate observable, reversible choices; remove rules that no longer earn their context cost. **Action:** make the rule-to-judgment boundary explicit so compounding does not become instruction accretion.

## A second tab that lands on the right slide

The want: a student working an exercise opens another exercise's instructions in a second browser tab and keeps it open beside their Claude session. Maintainer's framing: *"new tab is essential to allow for jumping between claude sessions and instructions. Browser back does not help in that."*

The built workbook carries one stable `id="exercises-<slug>"` per inlined exercise, and long-read honours them natively, so only slides-mode readers are stranded, and the deck is where there is no back.
