### [Finding 5] MAJOR — Organizational Knowledge Erosion: Fourth Voice Confirmed + Academic Corroborators

**Source 1 (Fourth voice — PRACTITIONER DIRECT):** `https://rickpollick.com/blog/adr-comeback-anchoring-agentic-engineering-teams` — [practitioner direct — Rick Pollick] (May 11, 2026)
**Source 2 (Academic — CORROBORATOR):** `https://arxiv.org/html/2604.16323` — [academic/research — Casserini, Facchini, Ferrario / ETH/IDSIA/SUPSI] (April 21, 2026)
**Source 3 (Research — CORROBORATOR):** `https://blog.sigplan.org/2026/04/21/repositories-are-human-agent-knowledge-factories/` — [practitioner analysis — de Halleux, Syme, Zorn / Microsoft Research + GitHub Next] (April 21, 2026)
**Date:** August 16, 2026 (sources from April–May 2026)
**Agent level:** team/company
**What:**

**Fourth voice — Rick Pollick (May 11, 2026):**
Independent practitioner names "agentic drift" = "a slow, plausible erosion of architectural intent, committed in small PRs, each of which looks like a reasonable refactor on its own merits." Core mechanism: agents operate with "no memory of why the existing design exists, because the existing design is mostly comments, structure, and naming, and not a written record of the constraints it is satisfying." Concrete incident (first-hand, "last quarter"): payments service agent removed idempotency layer that prevented double-charging during prior Black Friday outage. Agent didn't know why it existed. Change looked like a reasonable refactor. No one noticed until the next relevant failure. Predates Ronacher (July 13) and Osmani (July 20) by two months — independent convergence confirmed. Proposes ADRs as mitigation.

**Academic corroborator — Casserini/Facchini/Ferrario (April 21, ETH/IDSIA/SUPSI):**
"Agentic entropy" = ongoing process by which autonomous updates diverge from architectural intent. Three mechanisms: process-level drift, semantic instability (refactoring without constraint knowledge), reviewer capacity collapse (human oversight becomes passive rubber-stamping as velocity exceeds verification capacity). "Cognitive debt" = erosion of developers' system-level mental models as they delegate work to agents.

**Research corroborator — de Halleux/Syme/Zorn (April 21, Microsoft Research/GitHub Next):**
"Inaccessible Knowledge" anti-pattern: "A convention exists only in one developer's head. The agent violates it, the human corrects it but doesn't write it down." Agents lack access to "hallway conversations, Slack discussions, and institutional memory." Based on AVA deployment where ~90% of code was agent-authored. Agents produced "functionally correct but conventionally wrong" code early on.

**Full convergence map:**

**Evidence level:** Level 3 confirmed (4 independent practitioner-direct voices across 4 months; 2 additional academic/research corroborators; same mechanism named independently across solo builders, academic labs, and Microsoft Research).
