# Compounding yarn in Agents 101: the spine to align on

Read with `README.md` (rules, fixer brief, checks) and `ae101-yarn.md` (verification model). AE101's compounding yarn, studied at slide, exercise and figure level, is summarised in section 3.

## 1. Spine phrase and fixed contrast

**Spine:** the next run starts from what the last one left. **Contrast:** a chat starts from zero.

Both are already on the pages; they are the handle, so reuse them word for word and point them at a bigger target each module (AE101 move 5). Existing anchors:
- M2 Key Concepts: "A system compounds around your challenge: each new source sharpens what is already there. A chat starts from zero."
- M2 exercise point (build-your-challenge-memory): "Together they compound: each cycle starts from what the last one left."
- M2 lecture (compounding.md): "growing but not compounding", "sharper instead of longer", "problem four starts ahead".
- M3 lecture (when-to-split-an-agent): "A file can be read later: by you, by another agent, by next week's run."
- M4 exercise point (audit-your-agent): "it carries to the next agent".
- M6 exercise point (eval-loop): "The next run, on any topic, starts from the tighter tactic on disk."
- M8 Key Concepts: "Every improvement stays on disk; the next agent starts from it."

Second handle: **sharpen** (M1 "Each round sharpens the file", M2 "sharper instead of longer", M4 "Sharpen it where the method proves thin", M6 "sharpens the generator's tactic", M8 "makes the next description sharper"). Second contrast: **compounding or only growing** (M2 LO and lecture).

## 3. AE101 craft to copy (compounding, structural)

- Shape changes every module: add, place, sharpen, fill, encode, subtract, automate. Never the same size twice.
- Plant, then pay off: "this will bloat almost immediately" (M1) → "Rules have a ceiling" (M2) → cut one rule (M6).
- Exercise "The point:" lines carry the yarn in one clause.
- Next lines hand the artifact forward: "Your rules file gets read at the top of that session."
- Retroactive naming in the debrief lecture; a ladder (fix → memory → skill → system) instead of a recap.
- One figure re-issued with one state change (map-engine x4; double-loop M2 → M6).
