# Agents 101 first-start impressions

The welcome version averages **4.35/5 stars** across 30 simulated starts. The matched decimal baseline averages **4.34/5**. Scores are effectively flat. All 30 reads in each batch predict getting to the first game.

Each of ten synthetic personas reads the workbook HTML in three fresh calls. Both conditions use the same question, model and Mac or Windows profile. The reads assume Cowork access and the demonstrations described by the video placeholders.

The welcome explains what learners will practise, shows the first game, and previews the calendar summary. The folder step then names the folder to create and tells learners where to put it.

The most common remaining hesitation is finding the control that adds a folder in Claude Desktop. A short clip or still can show both the control and what the attached folder looks like. Readers still rely on the assumed demonstration for that handoff.

The scores range from 4.2 to 4.6 stars. The decimal scale runs from 1.0 to 5.0 in steps of 0.1. Anchor meanings run from unable to start through substantial help, detours and minor hesitation to a quick, obvious start.

This measures the model’s impressions of the route through the first game. Actual learner completion and time require observation in Cowork. Historical whole-star runs used a different scale and question.

The [structured results](latest-starts.json) include every current judgement, the baseline and intermediate results, and the hashes for the HTML used. Raw evidence is in the listed local directories under the ignored out folder.
