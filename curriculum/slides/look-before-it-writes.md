## Ask for the plan before the agent writes
<!--slide:look-before-it-writes-->

Before the agent writes several pages, changes anything you care about, or starts work that builds on itself, ask for the plan first: a numbered list of what it will read, what it will write, and where. In Claude Code, plan mode does exactly this.

One correction to the plan redirects every step after it. What the plan leaves open, the agent decides halfway through, inside work already moving, and you will not notice. A wrong call about which interviews count spreads into every page written after it.

Read the plan where you know most: the outcome, the customer's words, what the agent may touch.
