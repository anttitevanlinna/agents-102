How are practitioners calibrating whether a coding agent should act, and engineering its actions toward correctness?

**Cycle 178:** Current practice calibrates a delegation boundary: evidence, authority, deterministic execution checks, and rollback remain separate. Absolute correctness is defensible only for explicitly specified, machine-checkable properties; semantic intent remains probabilistic and human-owned.

**Gap:** No independently replicated production stack combines calibrated act/abstain routing, formal action enforcement, verified state transitions, and outcome monitoring across repositories and model changes.
