# Compounding yarn in Agents 101

Read with `README.md` (rules, fixer brief, checks). Supersedes the 2026-11-13 18:58 version, whose spine ("the next run starts from what the last one left") was persistence, not compounding (Antti: "what is compounding?", "this is not kiddie stuff. think agentic").

## 1. The concept, read agentically

**Compounding: work produces evidence, and the agents turn that evidence into a better system for the next work.** The agent does the improving, from the session, not from taste; you push back and own the yardstick. Each unit of work should make the next units easier (Klaassen, cited in AE101 `the-machine-you-just-met#what-compounds`). Storage is the precondition, not the concept: a file nobody improves is growing, not compounding.

## 2. How the meaning grows (three axes, never the same size twice)

- **What the agents improve:** one output's rules (M1) → the rules every agent in the directory reads, and a memory new sources sharpen (M2) → the rules between agents (M3) → a method packaged as a skill any agent loads (M4) → a judge that checks agents' claims (M5) → the generator's own tactic, under a fixed judge (M6) → an artifact in a teammate's hands (M7) → the agents themselves (M8).
- **Who does the improving:** the agent, with you pushing back (M1–M5) → the loop, with nobody in it, while you are away (M6) → your agent improving your agents, and the agent that improves them (M8).
- **What compounds:** the output → the system → across people (absorption, M7) → how fast you and your organisation learn (M8).
- **Subtraction counts.** A rule removed because the evidence killed it is compounding (A101 M1 prompt "drop", M6 prompt "remove a rule that fired on the wrong thing"; AE101 M6 cut one rule).

## 4. AE101 craft to copy (structure)

Shape changes every module (add, place, sharpen, fill, encode, subtract, automate). Plant, then pay off. The compound step named the same each time while its target changes. Exercise "The point:" lines carry the yarn in one clause. Next lines hand the improved artifact forward. One figure re-issued with one state change (map-engine x4). A ladder instead of a recap.

## 5. Reject list for the critic

Shallow: saving, keeping, persistence, "starts from", files "staying". Additive: any new sentence, label, recap, callout. Not agentic: the student writing or polishing rules by hand; "you build", "you sharpen" where the agent does it. Same size twice: a module repeating the previous module's target.
