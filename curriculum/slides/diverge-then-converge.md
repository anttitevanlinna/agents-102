## An agent widens in minutes; the choosing stays with you
<!--slide:diverge-then-converge-->

An agent can widen a list of opportunities, or of rough solutions, in minutes. Choosing between them is still yours, and it goes better when widening and choosing stay apart.

The UK Design Council's double diamond draws that rhythm twice. First the problem: Discover, then Define. Then the solution: Develop, then Deliver. Each diamond explores widely first and then narrows to focused action.

It is not four stages in a line. In the Council's words, "This is not a linear process": what a team learns can send it back to the beginning.
